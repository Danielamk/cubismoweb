# Cubismo — El Arte de Romper la Realidad

Una landing page moderna y editorial sobre el movimiento artístico del Cubismo, diseñada con una estética audaz inspirada en revistas de arte contemporáneo.

## 🎨 Características del Diseño

### Estilo Visual
- **Estética editorial moderna** con tipografías serif elegantes
- **Bloques de color cálidos** (terracota, crema, beige, verde oliva)
- **Imágenes superpuestas** con efectos de profundidad
- **Jerarquía tipográfica fuerte** con mucho espacio en blanco
- **Diseño responsivo** adaptado a todos los dispositivos

### Secciones Principales

1. **Hero Section** - Portada impactante con imagen principal y título gigante
2. **Quote Section** - Cita editorial destacada sobre el cubismo
3. **Press Section** - Logos de museos y medios reconocidos
4. **Claims Section** - Conceptos clave con formas abstractas
5. **Final CTA** - Llamada a la acción prominente

## 🛠 Tecnologías Utilizadas

- **HTML5** - Estructura semántica
- **CSS3** - Estilos avanzados con CSS Grid y Flexbox
- **JavaScript** - Interactividad y efectos suaves
- **Google Fonts** - Tipografías Playfair Display, Cormorant e Inter

## 🎯 Paleta de Colores

```css
--terracota: #C65D5A    /* Color principal */
```

## 📱 Características Responsivas

- Diseño adaptativo desde móviles hasta pantallas grandes
- Optimización de tipografías con `clamp()`
- Grid layouts que se adaptan automáticamente
- Efectos táctiles optimizados para dispositivos móviles

## ⚡ Efectos y Animaciones

- **Parallax suave** en elementos de fondo
- **Animaciones de entrada** cuando los elementos entran en viewport
- **Efectos hover** en botones y elementos interactivos
- **Smooth scrolling** entre secciones
- **Typing effect** en el título principal

## 🚀 Cómo usar

1. Abrir `index.html` en cualquier navegador moderno
2. La página es completamente responsiva y funcional
3. Todos los efectos funcionan sin necesidad de configuración adicional

## 🔧 Personalización

Para personalizar la página:

1. **Colores**: Modificar las variables CSS en `:root`
2. **Tipografías**: Cambiar las importaciones de Google Fonts
3. **Contenido**: Editar el HTML manteniendo las clases CSS
4. **Animaciones**: Ajustar los parámetros en `script.js`

## 📏 Consideraciones de Diseño

- **Accesibilidad**: Contrastes optimizados y navegación por teclado
- **Performance**: Imágenes optimizadas y CSS minimalista
- **SEO**: Estructura semántica y meta tags apropiados
- **Usabilidad**: Navegación intuitiva y call-to-actions claros
